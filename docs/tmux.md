# tmux

`~/.config/tmux` is a symlink to `user/dotfiles/.config/tmux`.

## Composition

```text
tmux.conf                 hub: only source-file lines, order matters
conf/
├── options.conf          prefix, indices, mouse, history, Wayland env
├── statusline.conf       status layout and window-tab formats
├── session.conf          resurrect/continuum options + vendor loaders
└── keys/
    ├── panes.conf        prefix + hjkl, Shift+hjkl resize
    ├── windows.conf      windows/splits + winmenu aliases
    ├── copy-mode.conf    vi copy-mode + smooth wheel
    └── reload.conf       prefix r
scripts/
├── winmenu.sh            full-screen popup switcher
└── smooth-scroll.sh      server-timer wheel animation
themes/
├── mocha.conf            tracked Catppuccin fallback
├── noctalia.conf         generated by Noctalia, ignored
└── README.md             fallback/generated policy
vendor -> ../../../../vendor/tmux
```

`tmux-resurrect` and `tmux-continuum` live in `vendor/tmux/`; the symlink keeps
the config paths stable. `VENDOR.md` records upstream and versions. TPM,
catppuccin/tmux and tmux-yank were removed because nothing sourced them.

## Theme

`themes/mocha.conf` defines the palette and fallback styles.
`themes/noctalia.conf` is generated from the wallpaper palette, ignored by git,
and sourced last. Noctalia currently overrides backgrounds, popups, menus,
borders and the clock, but not `status-left/right` or the window-tab formats;
that is intentional until Noctalia owns the whole status line.

`prefix r` re-sources the hub. `source-file` is additive, so removed style
options survive on a running server until `tmux kill-server`.

## Session service

`@continuum-boot on` makes continuum create
`~/.config/systemd/user/tmux.service`. The unit is generated outside git; its
`ExecStop` points at `~/.config/tmux/vendor/tmux-resurrect/scripts/save.sh`.
If vendor paths move, update or regenerate the unit.

## Validation

```bash
cd /etc/nixos
bash -n user/dotfiles/.config/tmux/scripts/*.sh

# fresh server: never test source-file on the live server
SOCK=tmux-check-$$
env -u XDG_CONFIG_HOME tmux -L "$SOCK" -f /dev/null new-session -d
env -u XDG_CONFIG_HOME tmux -L "$SOCK" source-file ~/.config/tmux/tmux.conf
tmux -L "$SOCK" show -g status-style
tmux -L "$SOCK" show -g @resurrect-save-script-path
tmux -L "$SOCK" kill-server
```

The theme check must use `env -u XDG_CONFIG_HOME`: the old config used
`$XDG_CONFIG_HOME/tmux/themes/noctalia.conf` and silently skipped the theme
when the variable was unset.
