# zsh

`ZDOTDIR` is set to `~/.config/zsh` by `/etc/zshenv.local`
(`common/system/environment.nix`); the directory is a symlink to
`user/dotfiles/.config/zsh`.

## Composition

```text
.zshenv      PATH, Hyprland socket; no compinit, no plugins
.zshrc       interactive guard -> manifest.zsh
manifest.zsh ordered list of rc/ modules
rc/
├── state.zsh       XDG paths, antidote/abbr/fzf-marks locations
├── history.zsh     HISTFILE, sizes, setopts (shared/global options explicit)
├── completion.zsh  completions fpath -> antidote completions bundle -> compinit
├── plugins.zsh     main bundle, fzf-tab, lazy wrappers
├── integrations.zsh fzf/zoxide cache, tmux clear/history
├── keys.zsh        history-search, autopair, zvm restore, Alt+V
├── prompt.zsh      starship with a plain fallback
└── python.zsh      uv/.venv autoactivation
plugins/
├── completions.txt # zsh-completions, loaded before compinit
├── main.txt        # ordered: fzf-tab before autosuggestions, z-sy-h last
└── lazy.txt        # abbr, fzf-marks, bd, forgit
completions/        # _nix hand-written, _opencode generated
vendor -> ../../../../vendor/zsh
```

The old generated `plugins.zsh` / `plugins_lazy.zsh` are gone. Antidote writes
static bundles to `$ANTIDOTE_HOME/static/{completions,main,lazy}.zsh`; the
default antidote cache is `~/.cache/antidote`.

## Generated state

| What | Path |
|---|---|
| history | `~/.local/state/zsh/history` |
| compdump | `~/.local/state/zsh/zcompdump` |
| zsh-abbr file | `~/.local/state/zsh/abbreviations` |
| fzf-marks file | `~/.local/state/zsh/fzf-marks` |
| fzf/zoxide cache | `~/.cache/zsh/{fzf,zoxide}.zsh` |
| antidote static bundles | `~/.cache/antidote/static/*.zsh` |
| starship config | `~/.config/starship.toml` — generated by Noctalia, not tracked |

`compinit -i -d "$ZSH_STATE_DIR/zcompdump"` is the only compinit call. An
earlier version loaded `ZSH/.zcompdump` by accident and skipped validation.

## Plugin order

1. `zsh-completions` must be on `fpath` before `compinit`.
2. `fzf-tab` loads after `compinit`, before `zsh-autosuggestions`.
3. `zsh-syntax-highlighting` must be last.
4. Lazy plugins are loaded on first use of `abbr`, `bd`, `mark`, `jump`,
   `pmark`, `dmark`, `fzm`, or a forgit alias. The wrapper removes itself
   before loading, so a failed load gives a clear “not found” instead of
   recursing after `source .zshrc`.

## Host and ISO

- The config never hardcodes `/home/Michael`; `$HOME`, `$ZDOTDIR`, and XDG
  variables are used. The OpenCode path is guarded with `[[ -d ... ]]`.
- On a fresh host/ISO the antidote static bundles do not exist until the first
  interactive shell; that shell may clone the four lazy + ten main plugins if
  the cache is empty. The ISO repo copy contains `vendor/zsh`, but not the
  clone cache.
- `~/.config/starship.toml` is generated by Noctalia; the ISO uses the plain
  prompt fallback until Noctalia renders it.

## Validation

```bash
cd /etc/nixos

# syntax
for f in user/dotfiles/.config/zsh/.zshenv \
         user/dotfiles/.config/zsh/.zshrc \
         user/dotfiles/.config/zsh/manifest.zsh \
         user/dotfiles/.config/zsh/rc/*.zsh; do
  zsh -n "$f"
done

# controlled interactive startup (does not touch the live shell)
ZDOTDIR=/etc/nixos/user/dotfiles/.config/zsh \
  zsh -i -c 'print -r -- "$_comp_dumpfile"; print -r -- "${_comps[nix]} ${_comps[opencode]}"'

# or
make zsh-check
```

`zsh-check` also rejects hardcoded `/home/Michael` and stale generated files
in the live directory.
