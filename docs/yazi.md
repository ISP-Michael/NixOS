# yazi

`~/.config/yazi` is a symlink to `user/dotfiles/.config/yazi`. Yazi 26.9.1
uses the native `ya pkg` package manager; `package.toml` is the lock/source of
truth for managed plugins.

## Composition

```text
yazi.toml      manager, [preview], [tasks], [plugin] preloaders/previewers
keymap.toml    c s / c m / F / + / -
init.lua       custom header, separator above status
theme.toml     tracked theme + large icon table
flavors/       noctalia.yazi generated by Noctalia, ignored
plugins/       vendored plugin trees
package.toml   managed plugins with rev/hash
Catppuccin Mocha.tmTheme
copy-uri.sh    file:// URIs for the system clipboard
```

## Plugins

| Plugin | Source | Deps | Wired |
|---|---|---|---|
| `office` | `ya pkg` | libreoffice, pdftoppm | office preloader/previewer |
| `smart-filter` | `ya pkg` | — | `F` |
| `video-grid` | `ya pkg` | ffmpeg, ffprobe | video preloader/previewer |
| `preview-sqlite` | `ya pkg` | sqlite3 | SQLite previewer |
| `preview-cbz` | `ya pkg` | unzip/7z | CBZ/CBR preloader/previewer |
| `zoom` | `ya pkg` | ImageMagick | `+`/`-` |
| `chmod` | manual vendored | chmod | `c m` |
| `piper` | manual vendored | glow (installed) | Markdown preview |

Removed 19.11.2026 because they were unused or could not work here:
`glow` (deprecated in favour of piper), `hexyl` (no binary), `mediainfo` (no
binary), `nbpreview` (no binary), `miller` (no `mlr`), `rich-preview` (no
`rich`), `wl-clipboard` (redundant with `copy-uri.sh`), `full-border` (not
enabled; the config has its own separator).

`package.toml` manages only the `ya pkg` entries. `chmod` and `piper` are
manual vendored trees; `ya pkg upgrade` will not touch them.

## What is new in Yazi 26.x

- `ya pkg` + `package.toml`: installs plugins, writes rev/hash locks, and
  updates them with `ya pkg upgrade`. Kept as the managed source of truth;
  vendored copies make the config work offline and on the ISO.
- `[plugin] prepend_preloaders` / `prepend_previewers`: rules are now
  ordered and composable; the config uses that for office, video, SQLite,
  CBZ and Markdown instead of relying on old plugin-specific keymaps.
- `[tasks] macro_workers/micro_workers`: limits ffmpeg jobs from
  video-grid; `[preview] max_width/max_height` gives zoom room.
- `init.lua` UI API (`ui.Style`, `ui.Layout`, `Root.layout`) is still the
  supported way to draw the custom header and separator.
- `[flavor]` plus the generated `noctalia.yazi` palette is the theme path;
  do not edit `flavors/noctalia.yazi/`.

Possible next additions: `yazi --debug`/`ya pkg list` in CI, `full-border`
only if the custom separator is removed, and `mediainfo`/`hexyl` only after
installing their CLIs.

## Validation

```bash
cd /etc/nixos
ya pkg list                     # package.toml parses and matches locks
# headless startup in a pty; quit after a second so the TUI has time to load
(sleep 1; printf 'q') | timeout 10 script -qec \
  'stty rows 30 cols 120; yazi /tmp' /dev/null \
  > /tmp/yazi-start.out 2>&1
grep -aiE 'error|invalid|panic|lua' /tmp/yazi-start.out
```

The theme file is a single Yazi input; the 700-line `[icon]` table cannot be
split into includes without a generator. Keep it tracked and generated
flavors ignored.

## ISO note

`iso-lite` does not carry `ffmpeg`, `sqlite3`, `glow` or `libreoffice`; those
previewers degrade to Yazi's native previews. `iso-media` has ffmpeg and
ImageMagick, `work` has LibreOffice, and `agent` has SQLite.
