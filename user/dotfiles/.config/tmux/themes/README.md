# tmux themes

- `mocha.conf` — tracked Catppuccin mocha fallback. It defines the palette and
  the styles used when Noctalia is absent.
- `noctalia.conf` — generated by Noctalia from the wallpaper palette, ignored
  by git, loaded last. Do not edit it by hand.

Noctalia currently overrides backgrounds, popups, menus, borders and the clock,
but not `status-left`, `status-right` or the window-tab formats: those stay
Catppuccin. This is intentional until Noctalia owns the complete status line.

`prefix r` re-sources the hub. Removed style options survive on a running
server until `tmux kill-server`, because `source-file` is additive.
