# yazi

`~/.config/yazi` is a symlink to this directory. Yazi 26.9.1 uses the native
`ya pkg` package manager (`package.toml`); the plugin directories stay
vendored so the config works offline and on the ISO.

- `yazi.toml` — manager options, preview/task limits, preloaders/previewers.
- `keymap.toml` — `c s` clipboard URIs, `c m` chmod, `F` smart filter,
  `+`/`-` preview zoom.
- `init.lua` — custom header and separator above the status bar.
- `theme.toml` — tracked theme, including the large icon table.
- `flavors/noctalia.yazi/` — generated by Noctalia, ignored by git.
- `package.toml` — managed plugins; `chmod` and `piper` are manual.

Plugin matrix and validation: `docs/yazi.md`.
