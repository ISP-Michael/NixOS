# Портал «Конференции.РФ» — демонстрационный экзамен 09.02.07

Django + PostgreSQL. Модули 1–3 — портал, модуль 4 — API заказов.

## Настройка одной командой

```bash
bash tools/pg_setup.sh
```

Поднимает сервер PostgreSQL, создаёт роль и базу портала, применяет
миграции и наполняет демо-данными. Скрипт безопасен для повторного
запуска. Подробности — раздел 5 [INSTRUKCIYA.md](INSTRUKCIYA.md).

Модуль 4 сюда не входит: он вариативный, его база выдаётся на
экзамене.

## Запуск

```bash
python manage.py runserver 8001    # портал   → http://127.0.0.1:8001
python api.py                      # модуль 4 → http://127.0.0.1:8081/orders
```

Учётные записи: администратор `Conf2027 / Demo77`,
пользователи `ivanov / user1234` и `petrova / user1234`.

Если зависимости не установлены:

```bash
python -m venv .venv
.venv/bin/pip install django 'psycopg[binary]'
```

Драйвер `psycopg` обязателен: Django сам PostgreSQL не поддерживает.
